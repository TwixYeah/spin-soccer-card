# Spin Soccer Card

Ukrainian football card collecting browser game — single-file HTML/React app with a Firebase Firestore backend.

## How to play
Just open `index.html` (or the live GitHub Pages link once enabled).

## Tech notes
- Single-file React app (Babel compiled in-browser)
- Persistent storage: Firebase Firestore (REST API, no SDK dependency)
- Firebase project: spin-soccer-card
